⚙️ Settings

🩺 Data Health Check

Scans your records for things like missing amounts, duplicate entries, and impossible balances — catches data problems before they show up in a statement.

🏛️ Library Name

Appears in the app title, statements, and PDFs. Change this to reuse the app for any library.

🏠 Owner Name

This name appears in "Given to Owner" fields everywhere.

👤 Default Coordinator Name

Auto-filled in the Coordinator → Owner form. You can still change it per entry.

💼 Default Collected By

Pre-selected in the "Money Collected By" dropdown when adding fees.

🌙 Dark Mode

Easier on the eyes for late-night entries.

🔔 Success Sound

Plays a short chime after saving a record or entry.

🙈 Hide Coordinator Names

Shows initials (e.g. "A.W.") on screen instead of full names. PDF statements still show full names.

🔒 Owner Login (Password)

Your password — full access to everything. Require a password to open this app on this device. Leave blank and save to remove the lock.

🔢 Use a numeric PIN instead of a password — faster to tap in one-handed

⚠️ This is a basic device-level lock, not encryption.

🔑 Forgot Password Recovery (optional but recommended)

Set a security question so you can reset your password yourself if you forget it — otherwise there's no recovery, and you'd need to clear browser data (losing all records) to get back in.

🤝 Coordinator Login

A separate password for your coordinator. They can only add Coord→Owner entries — no access to student fees, Settings, Backup, or editing/deleting anything. Requires an Owner Password to be set first. Leave blank and save to disable coordinator login.

👆 Fingerprint / Face Unlock

Use your device's fingerprint or face unlock instead of typing a password.

⚠️ Only works when this app is opened over HTTPS (e.g. your NitiForge site) — not when opened as a local file. Falls back to your password automatically if unavailable.

🛡️ Require Auth to Edit/Delete

Ask for your password or fingerprint every time before editing or deleting any record — not just when opening the app.

⏱️ Auto-Lock After Inactivity

Automatically re-locks the app if left untouched — useful if you step away from the desk. Requires a password or PIN to be set above.

💡 All settings are saved locally on this device. They persist across sessions.
